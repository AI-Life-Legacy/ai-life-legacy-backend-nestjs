이 문서는 테스트 계정 `test2027@test`에 저장된 생애 기록을 바탕으로, RAG 기반 라이프 아바타 시스템의 응답 평가 프롬프트를 검증하기 위한 사례를 정리한 것이다. 모든 판단은 각 케이스에 제시된 사용자 생애 기록, 사용자 질문, RAG 검색 결과, 시스템 최종 응답만을 기준으로 수행한다.

본 연구에서는 RAG 기반 라이프 아바타 응답 평가 프롬프트의 판별 가능성을 확인하기 위해, 테스트 계정의 생애 기록을 바탕으로 5개의 평가 사례를 구성하였다. 사례는 정확 응답, 부분 응답, 환각 응답, 기록 부재 시 유보 응답, 기록 부재 시 임의 생성 응답을 포함하도록 설계하였다. 평가 결과, 제안한 기준은 응답 정확도, 검색 문맥 적합도, 근거 없는 정보 생성 여부, 응답 유보 적절성을 구분하여 측정할 수 있음을 확인하였다.
