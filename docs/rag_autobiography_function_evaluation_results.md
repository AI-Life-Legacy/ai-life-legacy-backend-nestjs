# RAG 기반 사용자 맞춤형 AI 자서전 기능 평가 결과

## 1. 평가 개요

본 평가는 테스트 계정 `test2027@test`에 저장된 생애 기록을 바탕으로, RAG 검색 결과와 라이프 아바타 응답이 입력 기록을 얼마나 정확하게 반영하는지 확인하기 위해 수행하였다. 평가는 사용자 생애 기록, 사용자 질문, RAG 검색 결과 Top-4, 시스템 최종 응답만을 기준으로 수행하였다. 사용자 만족도, 문체의 자연스러움, 감성적 표현은 평가 대상에서 제외하였다.

생성 자서전의 핵심 정보 반영 평가는 실제 생성된 자서전 본문이 필요하지만, 현재 DB에는 `localhost:8000` 기준 PDF URL만 저장되어 있고 로컬 AI 서버의 PDF 파일은 확인되지 않았다. 따라서 본 테스트 결과에서는 라이프 아바타 기능 10개 케이스를 정량 평가하고, 자서전 핵심 정보 반영률은 평가 불가로 구분하였다.
